# Аурум

Сайт «Аурум» (ИП Торосян Артур Самвелович) — онлайн-кассы, фискальные накопители, внедрение 1С
и выпуск электронных подписей в Москве и Московской области. Офис: Москва, ул. Ухтомская, 6.

Копия сайта [altprime.ru](https://altprime.ru) по содержанию, со своим юрлицом, регионом
и оформлением. Тема «Бумага»: светлый тёплый фон, белые карточки, золото в акцентах,
тёмные полосы (лента, заявка, подвал) через класс `.theme-dark`. Заголовки — Playfair Display,
текст — Onest.

Тексты и устройство секций намеренно отличаются от altprime.ru: одинаковые тексты на двух
доменах поисковики считают дублем. Порядок: первый экран → услуги списком → каталог касс →
накопители → этапы работы → 1С → подпись → вопросы (с разметкой FAQPage) → заявка → карта.
Факты, характеристики техники и цены 1С — общие с altprime.ru, формулировки свои.

Прежний тёмно-золотой вариант оформления сохранён архивом `drafts/design-gold-dark.tar.gz`
(папки `app`, `components`, `public/logo` на 18.09.2026).

## Стек

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · TypeScript

## Разработка

```bash
npm install
npx next dev -p 3002
```

Порт 3002 — чтобы не пересекаться с altprime.ru (3000) и сайтом бара (3001).

## Где что менять

| Что | Где |
| --- | --- |
| Телефоны, почта, адрес, часы, реквизиты | `components/site/contacts.ts` |
| Логотип — знак «Монета» | `components/ui/Logo.tsx`, иконка сайта `app/icon.svg`, файл `public/logo/aurum.svg` |
| Цвета, шрифты, скругления | `app/globals.css` (`@theme`) и `app/layout.tsx` |
| Яндекс Метрика | `METRIKA_ID` в `components/site/analytics.ts` — пока не заведена |

## Переменные окружения

| Переменная | Что это |
| --- | --- |
| `SITE_URL` | адрес сайта, например `https://aurum.ru`; без неё — `http://localhost:3002` |
| `ALLOW_INDEXING` | `true` открывает сайт поисковикам; по умолчанию закрыт |
| `MAX_BOT_TOKEN`, `MAX_CHAT_ID` | бот MAX для заявок, как на altprime.ru |
| `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_TO` | дубль заявки письмом (Яндекс Почта, пароль приложения) |

Адрес и запрет индексации запекаются при сборке — после их смены нужна пересборка.
Каналы заявок читаются при запросе: хватает перезапуска. Пока каналы не заданы, заявка
остаётся только в журнале сервера (`delivery: 'skipped'`).

## До запуска

- купить домен и прописать его в `SITE_URL`;
- завести бота или почту для заявок, счётчик Метрики;
- уточнить часы работы (сейчас Пн–Пт 9–18, как у altprime.ru);
- когда появится карточка на Яндекс Картах и профиль в MAX — вписать в `contacts.ts`.

Поисковикам сайт закрыт тремя замками: `robots.txt` с `Disallow: /`, мета `noindex`
и (на сервере) заголовок `X-Robots-Tag` в Caddy. Открывать — все три сразу.
